Props Ad Mockups

Parameterized, iframe-able HTML mockups of social ad placements (Facebook, TikTok, Google Demand Gen, YouTube, Pinterest) for previewing creatives inside props.co.

  • v1 demo matrix — every platform × format plus edge cases
  • v1 renderer — v1/ad-mockup.html?platform=…&format=…
  • Repository & docs — param reference, Bubble integration, contract policy

The param schema is a versioned contract: changes to v1/ are additive-only. Breaking changes ship as v2/.
